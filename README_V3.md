# V3 水库施工进度百分比版

**已有 V2 安威川项目：在原项目目录解压更新包，保留 `.env`、数据集和已安装的依赖。** 不需要覆盖或下载照片，不需要再次安装 OpenCV。网关与模型仍使用现有 `.env`。

```bash
python3.12 src/run_aigawa.py --all
```

输出 `output/aigawa_v3/`，每组 `report.md`、`vlm_raw.json`、`prompt.txt`；多期汇总 `summary_reservoir.md`。验证已知坝体完成节点可执行 `python3.12 src/evaluate.py`。单组或其他水库仍用 `src/run_reservoir.py`。可选 `--context config/aigawa_context.json` 传入工程名称、已知坝型和范围，不含完成日期与真实进度标签。真实工程量文件仍可用 `--quantities` 指定。

## 百分比口径

- 大坝主体、溢洪道等各分项：模型依据完整计划范围的可辨认参考和已施工范围，直接估算0–100%及区间，不用阶段固定折算。分母不明、不可见或证据不足，返回 null。
- 可估算分项加权百分比：对具有估计的分项按示例权重归一化，不代表全水库。
- 全工程估算百分比：只有全部有正权重的分项都能估算时才提供单值；否则给可能范围（未知项按0–100%覆盖，不当作未开工）。范围是依赖输入和示例权重的条件范围，不是统计置信区间。
- 实际工程量百分比：用户提供已核实的实际量与计划量后独立计算；不是模型从照片直接测得的体积或合同进度。
- 同一组共同可估算工序的变化以百分点表示；不同可见范围不能直接相减，不强制单调上升。

## 验证与限制

本地24项测试通过，含旧功能、百分比范围、缺失/重复/异常输入、前后期百分比报告和汇总；离线回放测试使用构造响应，不是真实识别结果。原四期照片CV测试三组中两组通过（配准质量门槛不等于绝对精度）。当前环境无法解析 API 网关域名，因此没有完成新的线上模型识别，也没有生成真实的四期百分比。默认使用真实裁切照片，不使用 AI 重绘图。已知2022年2月坝体填筑完成标签仅用于验证，未注入提示词。其余期没有实际填筑工程量标签，不能计算多期定量准确率。保留原房建评分功能。
