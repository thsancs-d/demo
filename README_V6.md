# V6 证据优先提示词与分项计算

新识别使用 `src/progress_tracker.py` 中的 `build_update_prompt()`，版本标记 `v6-evidence-first`。分项先辨认范围、已完成及剩余工作，再估算百分比；不再让模型独立提交总工程百分比。历史分项证据及原图仍保留，但不再在历史输入中提供总体数字，以减少锚定。SSIM 只作为辅助。

总工程百分比由固定示例权重及分项点估计加权求和。未直接估算的项目仅在有具体依据时可提供 `inferred_stages`；程序校验数值范围、重复项和依据字段，不能核实文字证据真实性。如果本期覆盖达到70%但仍有未知分项，以可见分项加权平均外推剩余项目，并逐项记录这一未验证假设。低于70%不输出单值。原有保守可能范围仍将未直接观察项目作为0–100%处理；该范围并非统计置信区间。所有百分比均是影像估算，不是实际工程量，示例权重不是合同权重。

## 使用

将完整包中的文件合并进原工程目录，保留 `.env` 和 `output/`。之前的 V5 历史不会被改写为 V6 推断值。已有日期会自动跳过，新的日期会使用 V6 提示词。`--refresh-only` 只刷新历史展示，不能让模型重新识别。

如需独立验证新版提示词，使用一个新的输出目录（需重新调用 API）：

```bash
python3.12 src/run_aigawa.py --all --out output/aigawa_v6
```

或逐期使用 `--new-image ... --date ... --out output/aigawa_v6`。之后追加照片时必须使用同一个 `--out`。

实际送给模型的提示词保存在每期 `observations/<日期>/prompt.txt` 中。最新报告和 JSON 记录提示词版本、推断项目及外推假设。旧版本和新版本不能直接当作同口径精度对比。

## 验证

本地单元/集成测试和离线模拟模型响应测试通过；未调用线上 API，未验证真实工程完成率。默认仍使用真实裁切图，不用生成式高清修复图作为事实依据。
