# V7 累计施工进度：历史证据与请求审计

## 使用
保留原 `.env` 和 `output/`。本包无密钥。默认入口仍为 `src/run_aigawa.py`。旧 V6 历史继续使用分项加权算法，V5 及以前保留旧算法；不会因版本升级而改写旧进度方法。

- `python3.12 src/run_aigawa.py --all --out output/aigawa_v7`：独立目录完整测试（四次 API 调用）。
- `python3.12 src/run_aigawa.py --new-image data/new.jpg --date 2022-03-01`：默认目录追加一期（日期必须晚于已有最新期）。如使用独立目录，后续所有命令应带同一个 `--out`。
- `python3.12 src/run_aigawa.py --refresh-only`：从默认目录旧历史生成报表，不调用 API。

## 输入和输出
首期发送原图，第二期去重发送基准兼上期图及本期图，其后发送基准、上期、本期原图。CV 通过才额外附加 SSIM 差分图。图像前的标签、提示词中的编号和请求清单均使用同一角色列表。历史 JSON 包含各期总进度、区间、覆盖率、方法、分项证据与推断、外推记录；历史不是当前答案，不强制单调，不提供未来标签。旧照片归档的 SHA-256 校验可阻止错误替换。

每期 `observations/<日期>/prompt.txt` 保存实际提示文本，`request_manifest.json` 保存图片编号、角色、路径、散列和历史输入（不含 API 密钥或 base64 图像）；线上 `model_response.txt` 保存解析前响应文本。`history.json`、`latest_progress.json` 与最新报告含基准进度、上期进度和两种差值。比较的是估算变化，不是实测新增量。不同估算方法之间的差值标记为方法变化。

权重仍为示例权重。直接观察、推断和外推分开记录；覆盖低于 70% 时仍可能无单值。无法从照片验证隐蔽工程或真实工程量。生成式修复图片不用于默认识别。

## 验证
48 项单元/集成测试通过；用四期真实裁切照片与离线模拟模型响应检验请求清单、CV 配准、累计输出、图表和断点跳过。实际模型请求未运行：当前环境网关域名无法解析。日志中的离线百分比为模拟值，不是实测或 AI 识别结果。
