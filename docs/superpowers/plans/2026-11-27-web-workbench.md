# 工程进度识别工作台

用户已选择完整前后端，在现有本地项目中直接实现，无需发布。

- FastAPI 提供静态页面、实例、图片、异步识别任务和任务历史；复用现有固定镜头 CLI，单工作线程隔离各任务输出。
- 默认显示鵜川两期实例。明确标为历史模型结果经当前规则复核，保留未知百分比；变化框只落在本期原图。
- 支持 2–8 张 JPG/PNG/WebP、多日期、项目名和坝型。验证内容、尺寸、日期、重复图片，纠正 EXIF 方向。上传凭据仅服务端读取。
- 页面采用浅色工程监测工作台，前后原图、事件定位、分项状态、判读说明、上传弹窗、任务进度、失败重试和历史切换。
- 先验证 API 约束与真实离线管线，再实现后端和页面；运行原有回归及浏览器操作，启动本地预览。
