# 识别可信度与准确率评估

用户要求进一步优化识别准确率。本轮由实现者选择先提高累计进度输出的证据约束并补齐评估闭环；不将规则测试通过宣称为真实识别准确率提升。

## 方案与取舍

可选择更换模型/多次投票、增加结构化证据检查、或只增加评估。本轮采用证据检查加评估：当前只有四张小尺寸照片，唯一完成标签尚未独立核实，没有可用于模型选择的完整真值；多次模型调用增加成本且不保证正确。保留现有模型接口，不额外调用线上服务。

## 行为

- 新累计观察使用 V8。模型输出本期图片编号、归一化证据框、可见性、完整范围是否可辨认，以及比例估算方式；保留现有证据文本、状态、百分比区间和置信度。
- 当前图片编号必须对应本期原图，框须非空且在图内；visibility=clear、scope=full、basis=visible_extent 才能接受直接估算。高度比例/像素变化不得冒充完成率。
- 置信度至少 0.7，作为未标定的筛选阈值写入观察记录；不是准确率。施工中估算区间不能退化为单点。每条拒绝理由入档并显示报告。
- 新结果不以已知分项均值外推未知分项，不采纳模型推断作为本期直接观察；只有全部分项直接估算可用时给总工程单值，否则保留可估算分项完成率及全工程可能范围。由此可能增加无法估算的结果。
- 历史提示只提供证据、状态与来源，去除结构化旧百分比以减轻锚定；证据文字可能仍含数字，不宣称消除全部锚定。完整数值历史仍保存在 history.json。旧 V5/V6/V7 记录刷新维持原算法。跨 V7/V8 即使方法名相同也提示口径变化。
- 默认图片、CV 门槛、权重、模型接口不变；证据框只提供可核对位置，不证明语义正确。

## 评估

新增累计历史评估，保留旧双图评估入口。只评价 live 观察与人工明确 verified=true、含来源且与影像分项同口径的标签；不将模拟响应、隐蔽工程量或未核实里程碑算成真值。

输出 MAE、偏差、误差阈值内比例、区间覆盖和预测覆盖率；无足够标注/预测时输出 null，不输出虚假准确率。支持照片 SHA-256 核对，重复标签拒绝。提供无虚构真值的标签模板和可复制评估命令。

## 边界

本轮只改变默认累计识别流程，不改变旧双图算法；不覆盖现有监测输出，不读取 .env。新模拟夹具仅测试 V8 协议，旧夹具保留验证兼容性。实际效果需用户提供经核验标签后进行同样本对照。
